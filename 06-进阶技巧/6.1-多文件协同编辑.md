# 6.1 多文件协同编辑

## 场景描述

你需要让 Claude Code 同时编辑多个文件（如更新路由、控制器、模型），但不知道如何让 Claude Code 理解文件间的关联。用 Claude Code 可以快速**多文件协同编辑**、**保持代码一致性**。

本章案例：用 Claude Code 同时更新**路由、控制器、模型**（添加新字段）。

---

## 核心目标

- **多文件编辑**：让 Claude Code 同时编辑多个文件
- **代码一致性**：确保路由、控制器、模型保持一致
- **增量更新**：只修改必要的部分，不重写整个文件
- **验证结果**：确保修改后功能正常

---

## 完整工作流

### 第一步：准备多文件项目（2分钟）

假设我们有一个待办 API 项目，包含以下文件：

**`routes/todos.js`**（路由）：

```javascript
const express = require('express');
const router = express.Router();
const todoController = require('../controllers/todoController');

router.post('/', todoController.create);
router.get('/', todoController.getAll);
router.get('/:id', todoController.getById);
router.put('/:id', todoController.update);
router.delete('/:id', todoController.delete);

module.exports = router;
```

**`controllers/todoController.js`**（控制器）：

```javascript
const Todo = require('../models/Todo');

const todoController = {
  create: async (req, res, next) => {
    try {
      const { title, description } = req.body;
      const todo = new Todo({ title, description });
      await todo.save();
      res.status(201).json(todo);
    } catch (error) {
      next(error);
    }
  },
  
  getAll: async (req, res, next) => {
    try {
      const todos = await Todo.find({ userId: req.user.id });
      res.json(todos);
    } catch (error) {
      next(error);
    }
  },
  
  // ... 其他方法
};

module.exports = todoController;
```

**`models/Todo.js`**（模型）：

```javascript
const mongoose = require('mongoose');

const TodoSchema = new mongoose.Schema({
  title: { type: String, required: true },
  description: { type: String, default: '' },
  completed: { type: Boolean, default: false },
  userId: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
  createdAt: { type: Date, default: Date.now }
});

module.exports = mongoose.model('Todo', TodoSchema);
```

### 第二步：让 Claude Code 多文件协同编辑（5分钟）

**需求**：给待办事项添加 `dueDate`（截止日期）和 `priority`（优先级）字段。

对 Claude Code 说：

```
请帮我给待办 API 添加两个新字段：
1. dueDate（截止日期，Date 类型，可选）
2. priority（优先级，枚举：low / medium / high，默认 medium）

需要修改的文件：
- models/Todo.js（添加字段定义）
- controllers/todoController.js（处理新字段）
- routes/todos.js（不需要修改）

请同时更新所有相关文件，保持代码一致性。
```

**Claude Code 会同时修改多个文件**：

#### 1. 修改 `models/Todo.js`

```javascript
const mongoose = require('mongoose');

const TodoSchema = new mongoose.Schema({
  title: { type: String, required: true },
  description: { type: String, default: '' },
  completed: { type: Boolean, default: false },
  dueDate: { type: Date, default: null },  // ← 新增字段
  priority: { type: String, enum: ['low', 'medium', 'high'], default: 'medium' },  // ← 新增字段
  userId: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
  createdAt: { type: Date, default: Date.now }
});

module.exports = mongoose.model('Todo', TodoSchema);
```

#### 2. 修改 `controllers/todoController.js`

```javascript
const Todo = require('../models/Todo');

const todoController = {
  create: async (req, res, next) => {
    try {
      const { title, description, dueDate, priority } = req.body;  // ← 添加新字段
      const todo = new Todo({
        title,
        description,
        dueDate: dueDate || null,  // ← 处理新字段
        priority: priority || 'medium',  // ← 处理新字段
        userId: req.user.id
      });
      await todo.save();
      res.status(201).json(todo);
    } catch (error) {
      next(error);
    }
  },
  
  update: async (req, res, next) => {
    try {
      const { title, description, completed, dueDate, priority } = req.body;  // ← 添加新字段
      const todo = await Todo.findByIdAndUpdate(
        req.params.id,
        { title, description, completed, dueDate, priority },  // ← 更新新字段
        { new: true, runValidators: true }
      );
      if (!todo) {
        return res.status(404).json({ error: 'Todo not found' });
      }
      res.json(todo);
    } catch (error) {
      next(error);
    }
  },
  
  // ... 其他方法
};

module.exports = todoController;
```

**关键点**：
- Claude Code 同时修改了 `models/Todo.js` 和 `controllers/todoController.js`
- 保持了代码一致性（新字段在模型和控制器中都处理了）

### 第四步：让 Claude Code 添加参数校验（3分钟）

根据验证报告，让 Claude Code 添加参数校验：

```
请帮我添加参数校验：
1. dueDate 必须是合法日期（ISO 8601 格式）
2. priority 必须是 low / medium / high 之一

请修改 routes/todos.js。
```

**Claude Code 会修改 `routes/todos.js`**：

```javascript
const express = require('express');
const { body } = require('express-validator');
const router = express.Router();
const todoController = require('../controllers/todoController');
const validate = require('../middlewares/validator');

router.post('/', [
  body('title').notEmpty().withMessage('Title is required'),
  body('dueDate').optional().isISO8601().withMessage('Due date must be a valid date'),
  body('priority').optional().isIn(['low', 'medium', 'high']).withMessage('Priority must be low, medium, or high'),
  validate
], todoController.create);

router.put('/:id', [
  body('title').optional().notEmpty().withMessage('Title cannot be empty'),
  body('dueDate').optional().isISO8601().withMessage('Due date must be a valid date'),
  body('priority').optional().isIn(['low', 'medium', 'high']).withMessage('Priority must be low, medium, or high'),
  validate
], todoController.update);

router.get('/', todoController.getAll);
router.get('/:id', todoController.getById);
router.delete('/:id', todoController.delete);

module.exports = router;
```

## 核心技巧

### 1. 让 Claude Code "同时编辑多个文件"

❌ **不好**：一个文件一个文件地修改（容易漏改）
✅ **好**：明确说出要修改的所有文件

```
请帮我修改以下文件：
1. models/Todo.js（添加字段）
2. controllers/todoController.js（处理新字段）
3. routes/todos.js（添加参数校验）

请同时更新所有文件，保持一致性。
```

---

### 2. 用"增量更新"，别重写整个文件

❌ **不好**：让 Claude Code 重写整个文件
✅ **好**：只修改必要的部分

```
请帮我给 Todo 模型添加 dueDate 和 priority 字段，
只修改必要的地方，不要重写整个文件。
```

**原因**：
- 减少出错概率
- 保留原有的代码注释和格式

---

### 3. 修改后一定要验证一致性

❌ **不好**：修改完就完事，不验证
✅ **好**：让 Claude Code 生成验证报告

```
请帮我验证多文件修改是否一致：
1. 模型是否定义了新字段
2. 控制器是否处理了新字段
3. 路由是否需要添加参数校验
```

---

### 4. 用 Git 管理多文件修改

每次多文件修改后都 commit，方便回滚：

```bash
# 多文件修改后
git add .
git commit -m "feat: 添加 dueDate 和 priority 字段（影响 models/、controllers/、routes/）"
```

## 常见问题

### Q1：Claude Code 多文件修改后，功能不正常怎么办？

把错误信息发给它：

```
多文件修改后，创建待办事项时报错：

ValidationError: `priority` is not a valid enum value

这是我的代码：

[粘贴 models/Todo.js 和 controllers/todoController.js]

请帮我修复。
```

---

### Q2：如何让 Claude Code 理解文件间的关联？

**方案：提供项目结构**

```
这是我的项目结构：

- routes/todos.js（路由）
- controllers/todoController.js（控制器）
- models/Todo.js（模型）

请帮我添加新字段 dueDate 和 priority，
并确保三个文件保持一致。
```

---

### Q3：如何避免多文件修改冲突？

**方案：分步修改**

```
第一步：修改 models/Todo.js（添加字段定义）
第二步：修改 controllers/todoController.js（处理新字段）
第三步：修改 routes/todos.js（添加参数校验）
```

**原因**：分步修改容易定位问题。
