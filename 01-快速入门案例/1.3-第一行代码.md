# 1.3 让 Claude Code 帮你写第一行代码

> 不会编程？没关系。让 Claude Code 做你的编程老师。

## 🎯 场景描述

假设你：

- 知道要做什么，但不会写代码
- 或者会一点，但不确定怎么开始
- 或者很久没写代码，手生了

你的需求：**写一个 Python 脚本，批量重命名文件**。比如把 `IMG_20240101_001.jpg` 改成 `2024-01-01-001.jpg`。

## ✨ Claude Code 做法

### 不需要知道怎么写，只需要说清楚要做什么

```bash
cd ~/Photos/vacation
claude
```

```
帮我写一个 Python 脚本：

功能：批量重命名当前目录下的 JPG 图片
规则：
- 文件名格式为 IMG_YYYYMMDD_编号.jpg
- 改成 YYYY-MM-DD-编号.jpg
- 比如 IMG_20240101_001.jpg → 2024-01-01-001.jpg
- 只处理 .jpg 文件，不递归子目录
- 先预览要改什么，确认后再执行
```

Claude Code 会生成类似这样的脚本：

```python
#!/usr/bin/env python3
"""批量重命名 JPG 图片文件名。"""

import os
import re

def parse_filename(filename):
    """解析旧文件名，返回新文件名。"""
    match = re.match(r'IMG_(\d{4})(\d{2})(\d{2})_(\d+)\.jpg', filename, re.IGNORECASE)
    if not match:
        return None
    year, month, day, num = match.groups()
    return f"{year}-{month}-{day}-{num}.jpg"

def preview_renames(directory):
    """预览重命名结果。"""
    renames = []
    for f in sorted(os.listdir(directory)):
        new_name = parse_filename(f)
        if new_name and new_name != f:
            renames.append((f, new_name))
    return renames

def main():
    directory = os.getcwd()
    renames = preview_renames(directory)

    if not renames:
        print("没有需要重命名的文件。")
        return

    print(f"找到 {len(renames)} 个文件待重命名：\n")
    for old, new in renames:
        print(f"  {old}  →  {new}")

    confirm = input(f"\n确认执行？(y/N): ").strip().lower()
    if confirm != 'y':
        print("已取消。")
        return

    for old, new in renames:
        old_path = os.path.join(directory, old)
        new_path = os.path.join(directory, new)
        os.rename(old_path, new_path)
        print(f"  ✅ {old} → {new}")

    print(f"\n完成！共重命名 {len(renames)} 个文件。")

if __name__ == '__main__':
    main()
```

## 🔧 进阶：让代码更健壮

拿到初版后，你可以继续让 Claude Code 改进：

```
给脚本加上这些改进：
1. 支持命令行参数指定目录，默认当前目录
2. 支持 --dry-run 参数只预览不执行
3. 文件名冲突时自动加后缀
4. 加上 undo 功能，记录操作日志，支持撤销
5. 支持 .jpeg 后缀
```

Claude Code 会逐步完善代码。比如加上 `--dry-run` 后：

```python
#!/usr/bin/env python3
"""批量重命名 JPG 图片文件名。"""

import argparse
import json
import os
import re
from datetime import datetime

LOG_FILE = ".rename_log.json"

def parse_filename(filename):
    """解析旧文件名，返回新文件名。"""
    match = re.match(r'IMG_(\d{4})(\d{2})(\d{2})_(\d+)\.jpe?g', filename, re.IGNORECASE)
    if not match:
        return None
    year, month, day, num = match.groups()
    return f"{year}-{month}-{day}-{num}.jpg"

def preview_renames(directory):
    """预览重命名结果。"""
    renames = []
    for f in sorted(os.listdir(directory)):
        new_name = parse_filename(f)
        if new_name and new_name != f:
            renames.append((f, new_name))
    return renames

def resolve_conflict(directory, new_name):
    """文件名冲突时自动加后缀。"""
    if not os.path.exists(os.path.join(directory, new_name)):
        return new_name
    base, ext = os.path.splitext(new_name)
    counter = 1
    while os.path.exists(os.path.join(directory, f"{base}_{counter}{ext}")):
        counter += 1
    return f"{base}_{counter}{ext}"

def main():
    parser = argparse.ArgumentParser(description="批量重命名 JPG 图片")
    parser.add_argument("directory", nargs="?", default=".", help="目标目录（默认当前目录）")
    parser.add_argument("--dry-run", action="store_true", help="只预览不执行")
    parser.add_argument("--undo", action="store_true", help="撤销上次重命名")
    args = parser.parse_args()
    directory = os.path.abspath(args.directory)

    # 撤销模式
    if args.undo:
        log_path = os.path.join(directory, LOG_FILE)
        if not os.path.exists(log_path):
            print("没有找到操作日志，无法撤销。")
            return
        with open(log_path) as f:
            log = json.load(f)
        for new, old in log["renames"]:
            old_path = os.path.join(directory, new)
            new_path = os.path.join(directory, old)
            if os.path.exists(old_path):
                os.rename(old_path, new_path)
                print(f"  ↩ {new} → {old}")
        os.remove(log_path)
        print("撤销完成！")
        return

    renames = preview_renames(directory)
    if not renames:
        print("没有需要重命名的文件。")
        return

    print(f"找到 {len(renames)} 个文件待重命名：\n")
    resolved = []
    for old, new in renames:
        final_name = resolve_conflict(directory, new)
        suffix = f" → {final_name}" if final_name != new else ""
        print(f"  {old}  →  {new}{suffix}")
        resolved.append((old, final_name))

    if args.dry_run:
        print("\n[dry-run] 以上为预览结果，未执行任何操作。")
        return

    confirm = input(f"\n确认执行？(y/N): ").strip().lower()
    if confirm != 'y':
        print("已取消。")
        return

    # 记录日志用于撤销
    log = {"time": datetime.now().isoformat(), "renames": {new: old for old, new in resolved}}

    for old, new in resolved:
        old_path = os.path.join(directory, old)
        new_path = os.path.join(directory, new)
        os.rename(old_path, new_path)
        print(f"  ✅ {old} → {new}")

    with open(os.path.join(directory, LOG_FILE), 'w') as f:
        json.dump(log, f, indent=2, ensure_ascii=False)
    print(f"\n完成！共重命名 {len(resolved)} 个文件。")
    print(f"如需撤销，运行：python3 rename_photos.py --undo")

if __name__ == '__main__':
    main()
```

## 💡 不会编程者的使用建议

### 1. 用自然语言描述需求

你不需要知道函数叫什么、语法怎么写。只需要说清楚：

```
我想做什么 → 什么格式 → 什么规则 → 什么限制
```

**例子**：不说"用正则匹配"，而是说"文件名格式为 IMG_日期_编号.jpg"。

### 2. 先跑通，再理解

```
运行成功后，帮我给每行代码加上中文注释。
```

先拿到能用的代码，再回头理解原理。这比先学语法再写代码效率高 10 倍。

### 3. 出错了直接贴

```
运行报错了：
Traceback (most recent call last):
  File "rename.py", line 15, in <module>
    ...
帮我修复。
```

不要自己 Google 错误信息——直接把报错贴给 Claude Code，它比搜索引擎更懂你的代码上下文。

### 4. 不会问，就问 Claude Code

```
这个正则表达式 r'IMG_(\d{4})...' 是什么意思？
逐个给我解释。
```

### 5. 让它帮你做版本管理

```
先帮我创建一个 git 仓库，每次改完提交一下
```

这样哪怕改坏了也能回退。新手最怕的就是"改完跑不起来了又回不去"。

## 🐛 新手常见问题

### "代码跑起来但结果不对"

```
脚本运行了，但有些文件没有被重命名
```

Claude Code 会检查代码逻辑，可能是正则没有覆盖到你的文件名格式。把没被处理的文件名贴给它：

```
这个文件没被重命名：photo_20240101_001.jpg
帮我调整正则，也支持 photo_ 开头的
```

### "我想要的和生成的不一样"

```
我不想用命令行确认，改成弹一个 GUI 窗口让我选
```

Claude Code 可以随时调整方案。你不是在跟它下棋，是在跟它对话。

### "看不懂生成的代码"

```
把这段代码像教小学生一样解释给我听
```

Claude Code 会用最通俗的语言解释，比任何教程都耐心。

### "不确定该提什么需求"

用这个模板：

```
我想做一个 [功能]，
输入是 [什么]，
输出是 [什么]，
限制是 [什么]
```

比如：

```
我想做一个 文件分类工具，
输入是 指定目录，
输出是 按文件类型分到不同子文件夹，
限制是 不要动隐藏文件，先预览
```

## ⚠️ 注意事项

1. **别把 AI 当黑盒**——至少看看生成的代码在干什么，特别是涉及文件操作时
2. **先在测试目录跑**——批量操作文件前，先复制几份到临时目录测试
3. **用 git 做安全网**——让 Claude Code 帮你初始化 git，随时可以回滚
4. **逐步加功能**——别一次要太多，容易出错也不好调试
5. **操作前先预览**——批量操作类的脚本，一定要加预览/确认步骤
