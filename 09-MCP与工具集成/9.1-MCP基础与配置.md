# 9.1 MCP 基础与配置

> MCP（Model Context Protocol）让 Claude Code 连接外部工具和数据源，扩展它的能力边界。

## 🎯 什么是 MCP？

**MCP（Model Context Protocol）** 是一个开放协议，让 AI 助手能够：
- 读取本地文件系统
- 查询数据库
- 调用外部 API
- 访问 Web 内容
- 连接自定义工具

**简单说：MCP = Claude Code 的插件系统**

---

## 🚀 快速上手：配置你的第一个 MCP 服务器

### Step 1：找到配置文件

Claude Code 的 MCP 配置文件位置：
- **macOS/Linux**: `~/.config/claude/mcp.json`
- **Windows**: `%APPDATA%\claude\mcp.json`

如果文件不存在，创建一个。

### Step 2：添加 MCP 服务器

以 **文件系统访问** 为例：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/yourname/projects"
      ]
    }
  }
}
```

**解释：**
- `filesystem`: 服务器名称（自定义）
- `command`: 启动命令
- `args`: 参数列表
  - `@modelcontextprotocol/server-filesystem`: 官方的文件系统 MCP 服务器
  - `/Users/yourname/projects`: 允许访问的目录（可以配置多个）

### Step 3：重启 Claude Code

配置保存后，重启 Claude Code，你会看到：

```
✓ MCP 服务器已连接：
  - filesystem (就绪)
```

## 📦 常用 MCP 服务器推荐

### 1. 文件系统（Filesystem）
**功能**：读写本地文件
**安装**：
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/allowed/dir"]
    }
  }
}
```

**能做什么**：
```
你：帮我读取 ~/projects/my-app/README.md 的内容
Claude：[读取文件] 这个项目的 README 内容是...

你：把这段代码保存到 ~/Desktop/test.js
Claude：[写入文件] 已保存！
```

---

### 2. 数据库（PostgreSQL/MySQL）
**功能**：直接查询数据库
**安装**：
```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:password@localhost:5432/mydb"
      }
    }
  }
}
```

**能做什么**：
```
你：查询 users 表中最近 7 天注册的用户
Claude：[执行 SQL] 找到了 42 个用户...
```

---

### 3. Web 搜索（Brave Search）
**功能**：实时搜索互联网
**安装**：
```json
{
  "mcpServers": {
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-brave-search"],
      "env": {
        "BRAVE_API_KEY": "your-api-key-here"
      }
    }
  }
}
```

**能做什么**：
```
你：搜索最新的 React 19 特性
Claude：[搜索 Web] 根据搜索结果，React 19 的主要新特性包括...
```

---

## 🛠️ 实战案例：用 MCP 管理项目文档

### 场景描述

你有一个项目，文档分散在：
- 本地 Markdown 文件
- Notion
- Confluence

**目标**：用 Claude Code + MCP 统一管理

### 配置方案

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/you/docs"]
    },
    "notion": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-notion"],
      "env": {
        "NOTION_TOKEN": "secret_xxx"
      }
    }
  }
}
```

### 使用效果

```
你：把 docs/API设计.md 的内容同步到 Notion
Claude：[读取本地文件] → [写入 Notion] 已同步！Notion 页面链接：...

你：对比本地 docs/ 和 Notion 的文档，找出差异
Claude：[对比内容] 发现 3 处差异...
```

## ⚙️ 高级配置技巧

### 1. 多个目录访问

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/you/projects",
        "/Users/you/docs",
        "/tmp"
      ]
    }
  }
}
```

### 2. 自定义 MCP 服务器（Python）

创建一个简单的 MCP 服务器：

```python
# my-mcp-server.py
from mcp import Server, Tool

server = Server("my-tool")

@server.tool()
def get_weather(city: str) -> str:
    """获取指定城市的天气"""
    # 这里调用天气 API
    return f"{city} 的天气：晴，25°C"

if __name__ == "__main__":
    server.run()
```

配置到 Claude Code：

```json
{
  "mcpServers": {
    "my-weather": {
      "command": "python",
      "args": ["/path/to/my-mcp-server.py"]
    }
  }
}
```

## 🔍 调试 MCP 连接

### 问题：MCP 服务器连接失败

**检查清单**：
1. **命令是否存在**：手动运行 `npx -y @modelcontextprotocol/server-filesystem` 看是否能启动
2. **路径是否正确**：检查配置的目录是否存在
3. **环境变量**：确保 API Key 等环境变量正确
4. **查看日志**：Claude Code 启动时会有 MCP 连接日志

### 测试 MCP 服务器

```
你：列出当前可用的 MCP 工具
Claude：当前已连接的 MCP 服务器：
  1. filesystem - 可用工具：read_file, write_file, list_directory
  2. brave-search - 可用工具：web_search
```
