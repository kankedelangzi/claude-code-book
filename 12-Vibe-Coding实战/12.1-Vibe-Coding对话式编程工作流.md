## 什么是 Vibe Coding？

**Vibe Coding** 是一种全新的编程范式：你描述意图，AI 写代码，你审查结果、给反馈、推进方向。

### 核心理念

```
传统编程：你想 → 你写代码 → 你调试 → 你测试
Vibe Coding：你想 → 你描述 → AI写代码 → 你审查 → 你反馈 → AI改进
```

Andrej Karpathy（特斯拉前 AI 总监）在 2025 年发推说：

> "我现在写代码时完全不关注语法，只关注想解决什么问题，全靠 AI 生成代码。"

这就是 Vibe Coding 的精髓：**你负责「要什么」，AI 负责「怎么写」**。

### Vibe Coding vs 传统 AI 辅助编程

| 维度 | 传统模式（Copilot/Cursor Chat） | Vibe Coding（Claude Code） |
|------|-------------------------------|--------------------------|
| **交互方式** | 孤立的问答（Q&A） | 连续的对话流（Conversation Flow） |
| **关注点** | 代码补全、局部修改 | 需求理解、全局架构 |
| **上下文** | 短上下文，频繁丢失 | 长上下文，持续记忆 |
| **开发流程** | 你写，AI 提示 | AI 写，你审查 |
| **适用场景** | 代码片段、函数级别 | 完整功能、项目级别 |

## Vibe Coding 四大核心原则

### 原则 1：描述意图，而非实现

❌ **错误示例**（关注实现细节）：
```
"用 Express 框架创建一个路由 /api/users，使用 PostgreSQL 数据库连接，
编写 SQL 查询 SELECT * FROM users，然后用 JSON 格式返回..."
```

✅ **正确示例**（关注意图）：
```
"创建一个用户管理 API，支持查询所有用户，返回 JSON 格式"
```

**为什么？** AI 比你更懂实现细节，你只需要说清楚「要什么」。

### 原则 2：对话流，而非孤立问答

❌ **错误模式**（孤立问答）：
```
你："帮我写一个登录功能"
AI：（生成代码）
你：（复制代码，关闭对话）
（第二天）
你："帮我写一个注册功能"
AI：（不记得昨天的上下文）
```

✅ **正确模式**（连续对话流）：
```
你："帮我写一个登录功能"
AI：（生成代码）
你："好的，现在加一个「记住我」的复选框"
AI：（理解上下文，修改代码）
你："再添加一个「忘记密码」的链接"
AI：（继续迭代）
你："现在写注册功能，复用登录的样式"
AI：（记住之前的样式，保持一致）
```

### 原则 3：审查优先，信任但验证

Vibe Coding 不是「全自动编程」，而是「AI 起草，你审查」。

**审查清单**：
- ✅ 逻辑是否正确？
- ✅ 边界情况是否处理？
- ✅ 错误信息是否友好？
- ✅ 性能是否有问题？
- ✅ 安全隐患是否存在？

### 原则 4：迭代改进，小步快跑

不要试图一次性描述完所有需求，而是：
1. 先实现核心功能（MVP）
2. 测试、审查、反馈
3. 逐步添加功能
4. 持续优化和重构

## 实战案例：从零构建算卦平台

本案例基于真实项目，展示完整的 Vibe Coding 工作流。

### 项目需求

构建一个在线算卦平台，用户输入生辰八字，系统自动生成卦象和解读。

### 第一步：启动项目（描述意图）

**你的输入**：
```
创建一个算卦平台，使用 React + TypeScript + Tailwind CSS，
整体风格要神秘、古典，配色用紫色和金色。
```

**Claude Code 的输出**：
```bash
✅ 已创建项目骨架：
   - package.json (React + TypeScript + Tailwind)
   - src/App.tsx (主组件)
   - src/components/ (组件目录)
   - src/utils/ (工具函数)
   - tailwind.config.js (自定义主题色)
   
📦 正在安装依赖...
   - react, react-dom, typescript
   - tailwindcss, postcss, autoprefixer
   - zod (参数校验)
   
🎨 已配置 Tailwind 主题：
   colors: {
     mystic: {
       purple: '#6B21A8',
       gold: '#F59E0B'
     }
   }
   
🚀 开发服务器已启动：http://localhost:5173
```

**关键点**：你只描述了「要什么」（算卦平台、神秘风格），Claude Code 自动完成了所有技术细节（框架选择、依赖安装、配置）。

```
3. 提交后调用卦象生成算法
```
