## 完整工作流

### 第一步：准备待测试代码（2分钟）

假设我们有一个待办 API 的 Service 层（`todoService.js`）：

```javascript
const Todo = require('../models/Todo');

const todoService = {
  create: async ({ title, description }) => {
    if (!title) {
      const err = new Error('Title is required');
      err.status = 400;
      throw err;
    }
    
    const todo = new Todo({ title, description });
    await todo.save();
    return todo;
  },
  
  getAll: async (userId) => {
    const todos = await Todo.find({ userId });
    return todos;
  },
  
  getById: async (id) => {
    const todo = await Todo.findById(id);
    if (!todo) {
      const err = new Error('Todo not found');
      err.status = 404;
      throw err;
    }
    return todo;
  },
  
  update: async (id, updates) => {
    const todo = await Todo.findByIdAndUpdate(id, updates, { new: true, runValidators: true });
    if (!todo) {
      const err = new Error('Todo not found');
      err.status = 404;
      throw err;
    }
    return todo;
  },
  
  delete: async (id) => {
    const todo = await Todo.findByIdAndDelete(id);
    if (!todo) {
      const err = new Error('Todo not found');
      err.status = 404;
      throw err;
    }
    return todo;
  }
};

module.exports = todoService;
```

## 核心技巧

### 1. 让 Claude Code 生成"完整的测试用例"

❌ **不好**：只说"帮我生成测试"
✅ **好**：明确说出你要测试的方面

```
请为 todoService.js 生成单元测试，要求：
1. 用 Jest 框架
2. Mock 所有外部依赖
3. 覆盖所有函数（create / getAll / getById / update / delete）
4. 覆盖边界情况（参数错误、未找到）
5. 测试覆盖率 > 80%
```

---

### 2. Mock 外部依赖，别依赖真实数据库

❌ **不好**：测试时连接真实数据库
✅ **好**：用 Jest Mock

```javascript
// Mock Todo Model
jest.mock('../models/Todo', () => ({
  find: jest.fn(),
  findById: jest.fn(),
  save: jest.fn()
}));
```

**好处**：
- 测试速度快
- 不依赖外部环境
- 可以模拟各种错误场景

---

### 3. 测试覆盖率要"分级"，别追求 100%

| 级别 | 覆盖率 | 说明 |
|---|---|---|
| **核心功能** | 100% | 必须覆盖（create / update / delete） |
| **边界情况** | >80% | 尽量覆盖（参数错误、未找到） |
| **异常场景** | >50% | 可以后续补充（网络超时、数据库错误） |

**让 Claude Code 生成高覆盖率测试**：

```
请为 todoService.js 生成测试，覆盖率 > 80%，重点覆盖：
1. 核心功能（create / update / delete）
2. 边界情况（参数错误、未找到）
3. 异常场景（数据库错误、网络超时）
```

---

### 4. 用 Supertest 做集成测试

❌ **不好**：手动测试 API（用 curl 或 Postman）
✅ **好**：用 Supertest 自动测试


**好处**：
- 自动化测试，节省时间

### Q3：如何测试异步代码？

**方案 1：用 async/await**

```javascript
it('应该成功创建待办事项', async () => {
  const result = await todoService.create({ title: 'Test' });
  expect(result.title).toBe('Test');
});
```

**方案 2：用 done 回调**

```javascript
it('应该成功创建待办事项', (done) => {
  todoService.create({ title: 'Test' })
    .then(result => {
      expect(result.title).toBe('Test');
      done();
    });
});
```
