# 3.2 性能优化案例

## 场景描述

项目上线后性能不理想，用 Claude Code 可以快速**定位性能瓶颈**、**生成优化方案**、**自动重构代码**。

本章案例：优化一个慢查询频繁的 Express + MongoDB 项目。

---

## 核心目标

- **定位瓶颈**：让 Claude Code 找出性能热点（慢查询、内存泄漏、CPU 密集操作）
- **生成方案**：自动生成优化方案（加索引、缓存、并发控制）
- **自动重构**：让 Claude Code 修改代码（提升性能）
- **验证效果**：用压测工具验证优化效果

## 完整工作流

### 第一步：准备"性能问题代码"（2分钟）

假设我们有一个慢查询频繁的待办 API（`todoService.js`）：

```javascript
const Todo = require('../models/Todo');

const todoService = {
  // 问题1：没有索引，查询全表
  getAll: async (userId) => {
    const todos = await Todo.find({ userId });  // ← 没有索引，慢
    return todos;
  },
  
  // 问题2：N+1 查询问题
  getWithUserDetails: async (todoId) => {
    const todo = await Todo.findById(todoId);
    
    // 每个 todo 都要查询一次 user，N+1 问题
    const user = await User.findById(todo.userId);  // ← N+1 问题
    
    return { todo, user };
  },
  
  // 问题3：没有分页，一次返回所有数据
  getAllWithPagination: async (userId) => {
    const todos = await Todo.find({ userId });  // ← 数据量大时很慢
    return todos;
  },
  
  // 问题4：重复计算，没有缓存
  getStats: async (userId) => {
    const todos = await Todo.find({ userId });
    
    // 每次都要统计，没有缓存
    const stats = {
      total: todos.length,
      completed: todos.filter(t => t.completed).length,
      pending: todos.filter(t => !t.completed).length
    };
    
    return stats;  // ← 没有缓存，每次都要统计
  }
};

module.exports = todoService;
```

**问题清单**：
1. 缺少索引（查询全表）
2. N+1 查询问题（每个 todo 都查一次 user）
3. 没有分页（一次返回所有数据）
4. 没有缓存（重复计算）

Claude Code 会修改 `todoService.js`：

```javascript
const Todo = require('../models/Todo');

const todoService = {
  // 优化后：支持分页
  getAll: async (userId, page = 1, limit = 20) => {
    const skip = (page - 1) * limit;
    
    const todos = await Todo.find({ userId })
      .sort({ createdAt: -1 })
      .skip(skip)
      .limit(limit);
    
    // 返回分页元数据
    const total = await Todo.countDocuments({ userId });
    
    return {
      data: todos,
      meta: {
        total,
        page,
        limit,
        totalPages: Math.ceil(total / limit)
      }
    };
  }
};

module.exports = todoService;
```

**关键点**：一次只返回 20 条数据，响应时间大幅缩短。

**`config/redis.js`**：

```javascript

const redis = new Redis({
  host: process.env.REDIS_HOST || 'localhost',
  port: process.env.REDIS_PORT || 6379,
  password: process.env.REDIS_PASSWORD || null
});

redis.on('connect', () => {
  console.log('✅ Redis 连接成功');

redis.on('error', (err) => {
  console.error('❌ Redis 连接失败', err);
});

module.exports = redis;
```

**`services/todoService.js`**（添加缓存）：

```javascript
const Todo = require('../models/Todo');
const redis = require('../config/redis');

const todoService = {
  getStats: async (userId) => {
    // 先查缓存
    const cacheKey = `stats:${userId}`;
    const cached = await redis.get(cacheKey);
    
    if (cached) {
      return JSON.parse(cached);
    }
    
    // 缓存未命中，查询数据库
    const todos = await Todo.find({ userId });
    
    const stats = {
      total: todos.length,
      completed: todos.filter(t => t.completed).length,
      pending: todos.filter(t => !t.completed).length
    };
    
    // 写入缓存（TTL 5 分钟）
    await redis.setex(cacheKey, 300, JSON.stringify(stats));
    
    return stats;
  },
  
  // 数据更新时清除缓存
  clearStatsCache: async (userId) => {
    const cacheKey = `stats:${userId}`;
    await redis.del(cacheKey);
  }
};

module.exports = todoService;
```

**关键点**：加缓存后，QPS 提升 5-10 倍。
