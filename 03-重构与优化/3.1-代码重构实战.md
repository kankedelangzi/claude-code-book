# 3.1 代码重构实战

## 场景描述

你接手了一个"屎山"项目，代码混乱、难以维护。用 Claude Code 可以快速**识别问题代码**、**生成重构方案**、**自动重构**。

本章案例：重构一个混乱的 Express 项目（包含回调地狱、重复代码、命名混乱等问题）。

---

## 核心目标

- **识别问题**：让 Claude Code 找出代码中的"坏味道"
- **生成方案**：自动生成重构方案（分步实施）
- **自动重构**：让 Claude Code 修改代码（保持功能不变）
- **验证结果**：用测试确保重构不引入 bug

---

## 完整工作流

### 第一步：准备"问题代码"（2分钟）

假设我们有一个混乱的 Express 项目（`app.js`）：

```javascript
const express = require('express');
const app = express();
app.use(express.json());

// 问题1：回调地狱
app.post('/users', (req, res) => {
  const { name, email } = req.body;
  
  if (!name || !email) {
    return res.status(400).json({ error: 'Missing fields' });
  }
  
  db.query('SELECT * FROM users WHERE email = ?', [email], (err, results) => {
    if (err) {
      return res.status(500).json({ error: 'DB error' });
    }
    
    if (results.length > 0) {
      return res.status(400).json({ error: 'Email exists' });
    }
    
    db.query('INSERT INTO users (name, email) VALUES (?, ?)', [name, email], (err, result) => {
      if (err) {
        return res.status(500).json({ error: 'DB error' });
      }
      
      db.query('SELECT * FROM users WHERE id = ?', [result.insertId], (err, results) => {
        if (err) {
          return res.status(500).json({ error: 'DB error' });
        }
        
        res.json(results[0]);
      });
    });
  });
});

// 问题2：重复代码
app.put('/users/:id', (req, res) => {
  const { name, email } = req.body;
  
  if (!name || !email) {
    return res.status(400).json({ error: 'Missing fields' });
  }
  
  db.query('SELECT * FROM users WHERE email = ? AND id != ?', [email, req.params.id], (err, results) => {
    if (err) {
      return res.status(500).json({ error: 'DB error' });
    }
    
    if (results.length > 0) {
      return res.status(400).json({ error: 'Email exists' });
    }
    
    db.query('UPDATE users SET name = ?, email = ? WHERE id = ?', [name, email, req.params.id], (err) => {
      if (err) {
        return res.status(500).json({ error: 'DB error' });
      }
      
      db.query('SELECT * FROM users WHERE id = ?', [req.params.id], (err, results) => {
        if (err) {
          return res.status(500).json({ error: 'DB error' });
        }
        
        res.json(results[0]);
      });
    });
  });
});

app.listen(3000);
```

**问题清单**：
1. 回调地狱（嵌套 3 层）
2. 重复代码（参数校验、邮件检查逻辑重复）
3. 错误处理重复（每个查询都要判断 `err`）
4. 没有分层（所有代码写在 `app.js`）

### 第二步：让 Claude Code 识别问题（3分钟）

对 Claude Code 说：

```
请帮我分析当前代码的"坏味道"（code smells），重点检查：
1. 回调地狱（Callback Hell）
2. 重复代码（Duplicated Code）
3. 函数/变量命名不清晰
4. 缺少错误处理统一处理
5. 代码分层不清晰

请逐行分析，并生成重构建议。
```

**Claude Code 会生成类似报告**：

```markdown
# 代码重构分析报告

## 1. 回调地狱（Callback Hell）

**位置**：`app.post('/users')` 和 `app.put('/users/:id')`

**问题**：嵌套 3 层回调，难以阅读和维护

**建议**：改用 async/await 或 Promise

---

## 2. 重复代码（Duplicated Code）

**位置**：
- 参数校验逻辑（`if (!name || !email)`）重复 2 次
- 邮件唯一性检查逻辑重复 2 次
- 错误处理（`if (err)`）重复 6 次

**建议**：提取成独立函数或中间件

---

## 3. 命名不清晰

**问题**：`db` 未明确是什么（MySQL? MongoDB?）
**建议**：改为 `mysqlPool` 或 `mongoClient`

---

## 4. 缺少统一错误处理

**问题**：每个回调都要写 `if (err) { ... }`
**建议**：用 Promise 包装数据库查询，统一 catch

---

## 5. 代码分层不清晰

**问题**：路由、业务逻辑、数据操作全写在 `app.js`
**建议**：拆分为 controller / service / dao 三层

---

## 重构优先级

1. **高优先级**：解决回调地狱（改用 async/await）
2. **高优先级**：提取重复代码（参数校验、邮件检查）
3. **中优先级**：统一错误处理
4. **低优先级**：代码分层重构
```

#### 重构 1：用 async/await 解决回调地狱

```
请帮我用 async/await 重构以下代码，要求：
1. 用 util.promisify 或 mysql2/promise 包装数据库查询
2. 把所有回调改造成 await
3. 用 try-catch 统一错误处理

代码：

[粘贴 app.js 代码]
```

Claude Code 会生成类似代码：

```javascript
const express = require('express');
const mysql = require('mysql2/promise');
const app = express();
app.use(express.json());

// 创建数据库连接池
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: 'password',
  database: 'test',
  waitForConnections: true,
  connectionLimit: 10
});

// 创建用户
app.post('/users', async (req, res) => {
  try {
    const { name, email } = req.body;
    
    // 参数校验
    if (!name || !email) {
      return res.status(400).json({ error: 'Missing fields' });
    }
    
    // 检查邮件是否已存在
    const [existing] = await pool.query('SELECT * FROM users WHERE email = ?', [email]);
    if (existing.length > 0) {
      return res.status(400).json({ error: 'Email exists' });
    }
    
    // 插入用户
    const [result] = await pool.query('INSERT INTO users (name, email) VALUES (?, ?)', [name, email]);
    
    // 查询新创建的用户
    const [users] = await pool.query('SELECT * FROM users WHERE id = ?', [result.insertId]);
    
    res.json(users[0]);
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'DB error' });
  }
});

// 更新用户
app.put('/users/:id', async (req, res) => {
  try {
    const { name, email } = req.body;
    
    // 参数校验
    if (!name || !email) {
      return res.status(400).json({ error: 'Missing fields' });
    }
    
    // 检查邮件是否已存在（排除当前用户）
    const [existing] = await pool.query('SELECT * FROM users WHERE email = ? AND id != ?', [email, req.params.id]);
    if (existing.length > 0) {
      return res.status(400).json({ error: 'Email exists' });
    }
    
    // 更新用户
    await pool.query('UPDATE users SET name = ?, email = ? WHERE id = ?', [name, email, req.params.id]);
    
    // 查询更新后的用户
    const [users] = await pool.query('SELECT * FROM users WHERE id = ?', [req.params.id]);
    
    res.json(users[0]);
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'DB error' });
  }
});

app.listen(3000);
```

**关键点**：回调地狱解决了，但重复代码还在。

```
请帮我提取重复代码，要求：
1. 提取参数校验逻辑（封装成 validateUserInput 函数）
2. 提取邮件唯一性检查（封装成 checkEmailUnique 函数）
3. 提取统一错误处理（用 express-async-errors）

代码：

[粘贴上一步重构后的代码]
```

Claude Code 会生成类似代码：

```javascript
const express = require('express');
const mysql = require('mysql2/promise');
require('express-async-errors');  // 自动捕获 async 错误
const app = express();
app.use(express.json());

const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: 'password',
  database: 'test',
  waitForConnections: true,
  connectionLimit: 10
});

// 工具函数：参数校验
const validateUserInput = (name, email) => {
  if (!name || !email) {
    const error = new Error('Missing fields');
    error.status = 400;
    throw error;
  }
};

// 工具函数：检查邮件唯一性
const checkEmailUnique = async (email, excludeId = null) => {
  let query = 'SELECT * FROM users WHERE email = ?';
  let params = [email];
  
  if (excludeId) {
    query += ' AND id != ?';
    params.push(excludeId);
  }
  
  const [existing] = await pool.query(query, params);
  
  if (existing.length > 0) {
    const error = new Error('Email exists');
    error.status = 400;
    throw error;
  }
};

// 创建用户
app.post('/users', async (req, res) => {
  const { name, email } = req.body;
  
  validateUserInput(name, email);
  await checkEmailUnique(email);
  
  const [result] = await pool.query('INSERT INTO users (name, email) VALUES (?, ?)', [name, email]);
  const [users] = await pool.query('SELECT * FROM users WHERE id = ?', [result.insertId]);
  
  res.json(users[0]);
});

// 更新用户
app.put('/users/:id', async (req, res) => {
  const { name, email } = req.body;
  
  validateUserInput(name, email);
  await checkEmailUnique(email, req.params.id);
  
  await pool.query('UPDATE users SET name = ?, email = ? WHERE id = ?', [name, email, req.params.id]);
  const [users] = await pool.query('SELECT * FROM users WHERE id = ?', [req.params.id]);
  
  res.json(users[0]);
});

// 统一错误处理中间件
app.use((err, req, res, next) => {
  console.error(err);
  const status = err.status || 500;
  res.status(status).json({ error: err.message });
});

app.listen(3000);
```

**关键点**：重复代码提取了，但所有代码还在 `app.js`。

Claude Code 会生成分层结构：

**`dao/userDao.js`**：

```javascript
const pool = require('../config/database');

const userDao = {
  create: async (name, email) => {
    const [result] = await pool.query('INSERT INTO users (name, email) VALUES (?, ?)', [name, email]);
    const [users] = await pool.query('SELECT * FROM users WHERE id = ?', [result.insertId]);
    return users[0];
  },
  
  update: async (id, name, email) => {
    await pool.query('UPDATE users SET name = ?, email = ? WHERE id = ?', [name, email, id]);
    const [users] = await pool.query('SELECT * FROM users WHERE id = ?', [id]);
    return users[0];
  },
  
  checkEmailUnique: async (email, excludeId = null) => {
    let query = 'SELECT * FROM users WHERE email = ?';
    let params = [email];
    
    if (excludeId) {
      query += ' AND id != ?';
      params.push(excludeId);
    }
    
    const [existing] = await pool.query(query, params);
    return existing.length === 0;  // 返回 true 表示唯一
  }
};

module.exports = userDao;
```

**`services/userService.js`**：

```javascript
const userDao = require('../dao/userDao');

const userService = {
  createUser: async (name, email) => {
    // 参数校验
    if (!name || !email) {
      const error = new Error('Missing fields');
      error.status = 400;
      throw error;
    }
    
    // 检查邮件唯一性
    const isUnique = await userDao.checkEmailUnique(email);
    if (!isUnique) {
      const error = new Error('Email exists');
      error.status = 400;
      throw error;
    }
    
    // 创建用户
    return await userDao.create(name, email);
  },
  
  updateUser: async (id, name, email) => {
    // 参数校验
    if (!name || !email) {
      const error = new Error('Missing fields');
      error.status = 400;
      throw error;
    }
    
    // 检查邮件唯一性
    const isUnique = await userDao.checkEmailUnique(email, id);
    if (!isUnique) {
      const error = new Error('Email exists');
      error.status = 400;
      throw error;
    }
    
    // 更新用户
    return await userDao.update(id, name, email);
  }
};

module.exports = userService;
```

**`controllers/userController.js`**：

```javascript
const userService = require('../services/userService');

const userController = {
  create: async (req, res) => {
    const { name, email } = req.body;
    const user = await userService.createUser(name, email);
    res.json(user);
  },
  
  update: async (req, res) => {
    const { name, email } = req.body;
    const user = await userService.updateUser(req.params.id, name, email);
    res.json(user);
  }
};

module.exports = userController;
```

## 核心技巧

### 1. 让 Claude Code 分步重构，别一次性改完

❌ **不好**：让 Claude Code "一次性重构所有代码"
✅ **好**：分步重构，每步验证

```
第一步：解决回调地狱（改用 async/await）
第二步：提取重复代码（封装成函数）
第三步：代码分层（Controller / Service / DAO）
```

**原因**：分步重构容易回滚，一旦出错可以快速定位。

---

### 2. 用 "坏味道" 术语跟 Claude Code 沟通

Claude Code 懂软件工程术语，用专业术语沟通更高效：

- **回调地狱**：Callback Hell
- **重复代码**：Duplicated Code
- **长函数**：Long Method
- **上帝类**：God Class
- **意大利面代码**：Spaghetti Code

**示例**：

```
请帮我解决"回调地狱"问题，改用 async/await。
```

---

### 3. 重构后必须用测试验证

❌ **不好**：重构完就完事，不测试
✅ **好**：重构完立即运行测试

**让 Claude Code 生成测试**：

```
请为重构后的代码生成单元测试，覆盖：
1. 创建用户（成功/失败）
2. 更新用户（成功/失败）
3. 邮件唯一性检查
```

---

### 4. 用 Git 管理重构过程

每次重构一步就 commit 一次，方便回滚：

```bash
# 第一步：解决回调地狱
git add .
git commit -m "refactor: 用 async/await 解决回调地狱"

# 第二步：提取重复代码
git add .
git commit -m "refactor: 提取参数校验和邮件检查逻辑"

# 第三步：代码分层
git add .
git commit -m "refactor: 用三层架构重构代码"
```
