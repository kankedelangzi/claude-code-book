# 5.3 自动化脚本编写

## 场景描述

你需要编写自动化脚本（定时备份、文件批处理、数据同步），但不知道如何设计、调度、监控。用 Claude Code 可以快速**生成自动化脚本**、**配置定时任务**、**添加监控告警**。

本章案例：用 Claude Code 编写**文件自动备份脚本**（支持增量备份、日志记录、监控告警）。

- **脚本生成**：让 Claude Code 生成自动化脚本（Node.js 或 Shell）
- **定时调度**：让 Claude Code 配置定时任务（cron 或 node-schedule）
- **日志记录**：让 Claude Code 添加日志记录（Winston）
- **监控告警**：让 Claude Code 生成监控脚本（邮件/Slack 告警）

### 第一步：让 Claude Code 生成自动化脚本（10分钟）

对 Claude Code 说：

```
我想用 Claude Code 编写一个文件自动备份脚本，需求：
1. 备份源目录：/path/to/source
2. 备份目标目录：/path/to/backup
3. 增量备份（只备份修改过的文件）
4. 日志记录（Winston）
5. 监控告警（备份失败时发邮件）
6. 定时执行（每天凌晨 2 点）

请帮我生成完整的自动化脚本（scripts/backup.js）。
```

**Claude Code 会生成类似代码**：

#### `scripts/backup.js`

```javascript
#!/usr/bin/env node

const fs = require('fs-extra');
const path = require('path');
const crypto = require('crypto');
const schedule = require('node-schedule');
const logger = require('../config/logger');
const nodemailer = require('nodemailer');

// 配置
const CONFIG = {
  sourceDir: process.env.SOURCE_DIR || '/path/to/source',
  backupDir: process.env.BACKUP_DIR || '/path/to/backup',
  logDir: process.env.LOG_DIR || '/path/to/logs',
  retentionDays: parseInt(process.env.RETENTION_DAYS) || 7
};

// 计算文件哈希（用于检测文件是否修改）
const getFileHash = async (filePath) => {
  const content = await fs.readFile(filePath);
  return crypto.createHash('sha256').update(content).digest('hex');
};

// 增量备份
const incrementalBackup = async () => {
  try {
    logger.info('开始增量备份...');
    
    // 确保备份目录存在
    await fs.ensureDir(CONFIG.backupDir);
    
    // 读取上次备份的文件哈希
    const hashFile = path.join(CONFIG.backupDir, '.file-hashes.json');
    let fileHashes = {};
    if (await fs.pathExists(hashFile)) {
      fileHashes = await fs.readJson(hashFile);
    }
    
    // 遍历源目录
    const files = await fs.readdir(CONFIG.sourceDir);
    let backedUpCount = 0;
    
    for (const file of files) {
      const sourcePath = path.join(CONFIG.sourceDir, file);
      const backupPath = path.join(CONFIG.backupDir, file);
      
      // 跳过目录
      const stat = await fs.stat(sourcePath);
      if (!stat.isFile()) continue;
      
      // 计算文件哈希
      const fileHash = await getFileHash(sourcePath);
      
      // 增量备份：只备份修改过的文件
      if (fileHashes[file] !== fileHash) {
        await fs.copy(sourcePath, backupPath);
        fileHashes[file] = fileHash;
        backedUpCount++;
        logger.info(`备份文件：${file}`);
      }
    }
    
    // 保存文件哈希
    await fs.writeJson(hashFile, fileHashes);
    
    // 清理过期备份
    await cleanOldBackups();
    
    logger.info(`增量备份完成，共备份 ${backedUpCount} 个文件`);
    
    return { success: true, backedUpCount };
  } catch (error) {
    logger.error('备份失败', { error: error.message, stack: error.stack });
    await sendAlert('备份失败', error.message);
    throw error;
  }
};

// 清理过期备份
const cleanOldBackups = async () => {
  const files = await fs.readdir(CONFIG.backupDir);
  const now = Date.now();
  const retentionMs = CONFIG.retentionDays * 24 * 60 * 60 * 1000;
  
  for (const file of files) {
    if (file === '.file-hashes.json') continue;
    
    const filePath = path.join(CONFIG.backupDir, file);
    const stat = await fs.stat(filePath);
    
    if (now - stat.mtimeMs > retentionMs) {
      await fs.remove(filePath);
      logger.info(`删除过期备份：${file}`);
    }
  }
};

// 发送告警
const sendAlert = async (subject, message) => {
  try {
    const transporter = nodemailer.createTransporter({
      service: 'gmail',
      auth: {
        user: process.env.EMAIL_USER,
        pass: process.env.EMAIL_PASSWORD
      }
    });
    
    await transporter.sendMail({
      from: process.env.EMAIL_USER,
      to: process.env.ALERT_EMAIL,
      subject: `🚨 ${subject}`,
      text: message
    });
    
    logger.info('告警邮件已发送');
  } catch (error) {
    logger.error('发送告警邮件失败', { error: error.message });
  }
};

// 定时任务（每天凌晨 2 点）
const job = schedule.scheduleJob('0 2 * * *', async () => {
  logger.info('定时备份任务触发');
  try {
    await incrementalBackup();
  } catch (error) {
    logger.error('定时备份失败', { error: error.message });
  }
});

// 手动执行备份
if (require.main === module) {
  incrementalBackup()
    .then(result => {
      console.log('✅ 备份成功', result);
      process.exit(0);
    })
    .catch(error => {
      console.error('❌ 备份失败', error);
      process.exit(1);
    });
}

module.exports = { incrementalBackup };
```

const winston = require('winston');
const path = require('path');

// 日志格式
const logFormat = winston.format.combine(
  winston.format.timestamp({ format: 'YYYY-MM-DD HH:mm:ss' }),
  winston.format.errors({ stack: true }),
  winston.format.json()
);

// 创建 logger
const logger = winston.createLogger({
  level: process.env.LOG_LEVEL || 'info',
  format: logFormat,
  transports: [
    // 错误日志（单独文件）
    new winston.transports.File({
      filename: path.join(process.env.LOG_DIR || '/path/to/logs', 'error.log'),
      level: 'error',
      maxsize: 10485760,  // 10MB
      maxFiles: 5
    }),
    // 综合日志
    new winston.transports.File({
      filename: path.join(process.env.LOG_DIR || '/path/to/logs', 'combined.log'),
      maxsize: 10485760,
      maxFiles: 5
    })
  ]
});

// 开发环境：同时输出到控制台
if (process.env.NODE_ENV !== 'production') {
  logger.add(new winston.transports.Console({
    format: winston.format.simple()
  }));
}

module.exports = logger;

### 第四步：让 Claude Code 生成监控脚本（5分钟）

```
请帮我生成监控脚本，需要：
1. 定时检查备份日志（每 10 分钟）
2. 如果最近 24 小时内没有备份成功日志 → 告警
3. 发送告警通知（邮件 + Slack）
4. 生成监控脚本（scripts/monitor-backup.js）

请生成完整代码。
```

**Claude Code 会生成类似代码**：

#### `scripts/monitor-backup.js`

```javascript
const fs = require('fs');
const path = require('path');
const logger = require('../config/logger');

const LOG_FILE = path.join(process.env.LOG_DIR || '/path/to/logs', 'combined.log');
const ALERT_THRESHOLD_HOURS = 24;  // 24 小时内无备份成功 → 告警

// 检查备份日志
const checkBackupLogs = async () => {
  try {
    const content = await fs.promises.readFile(LOG_FILE, 'utf-8');
    const lines = content.split('\n');
    
    // 查找最近 24 小时内的备份成功日志
    const thresholdTime = Date.now() - ALERT_THRESHOLD_HOURS * 60 * 60 * 1000;
    const recentSuccess = lines.some(line => {
      if (!line.includes('备份完成')) return false;
      
      // 提取时间戳（假设格式：2026-05-17 10:00:00）
      const match = line.match(/^(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})/);
      if (!match) return false;
      
      const logTime = new Date(match[1]).getTime();
      return logTime >= thresholdTime;
    });
    
    if (!recentSuccess) {
      logger.warn(`最近 ${ALERT_THRESHOLD_HOURS} 小时内无备份成功`);
      await sendAlert(
        '备份告警',
        `最近 ${ALERT_THRESHOLD_HOURS} 小时内未检测到备份成功日志，请检查备份脚本是否正常运行。`
      );
    } else {
      logger.info('备份监控正常');
    }
  } catch (error) {
    logger.error('检查备份日志失败', { error: error.message });
  }
};

// 发送告警
const sendAlert = async (subject, message) => {
  // 发送邮件（参考 backup.js 中的实现）
  console.log(`🚨 告警：${subject}`);
  console.log(message);
};

// 每 10 分钟执行一次
setInterval(checkBackupLogs, 10 * 60 * 1000);

// 立即执行一次
checkBackupLogs();

console.log('📊 备份监控已启动...');
```

## 核心技巧

### 1. 让 Claude Code 生成"完整的自动化脚本"

❌ **不好**：只说"帮我写一个备份脚本"
✅ **好**：明确说出需求

```
请帮我生成自动化脚本，需求：
1. 增量备份（只备份修改过的文件）
2. 日志记录（Winston）
3. 监控告警（备份失败时发邮件）
4. 定时执行（每天凌晨 2 点）
```

---

### 2. 用 Winston 记录日志，别用 console.log

❌ **不好**：`console.log('备份完成')`
✅ **好**：`logger.info('备份完成', { backedUpCount: 5 })`

**好处**：
- 日志按日期轮转
- 包含上下文信息
- 方便监控和调试

---

### 3. 用 node-schedule 或 cron 配置定时任务

❌ **不好**：用 `setInterval`（不灵活）
✅ **好**：用 `node-schedule` 或 `cron`

```javascript
// 每天凌晨 2 点执行
const job = schedule.scheduleJob('0 2 * * *', () => {
  console.log('定时任务触发');
});
```

---

### 4. 监控告警要"分级"，别一出错就告警

| 级别 | 条件 | 动作 |
|---|---|---|
| **INFO** | 备份成功 | 只记录日志 |
| **WARN** | 备份时间超过 1 小时 | 记录日志，定期汇总 |
| **ERROR** | 备份失败 | 立即告警（邮件 + Slack） |

**让 Claude Code 生成分级告警规则**：

```
请帮我生成分级告警规则：
1. INFO：记录日志
2. WARN：每小时汇总
3. ERROR：立即告警
```
