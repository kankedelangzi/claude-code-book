# 2.4 配置文件管理

## 场景描述

项目中的配置文件（环境变量、数据库配置、第三方服务密钥）经常散落各处，难以管理。用 Claude Code 可以快速生成**统一、安全、易维护**的配置文件管理方案。

本章案例：为待办 API 项目生成**多环境配置管理**（开发/测试/生产）。

---

## 核心目标

- **统一管理**：所有配置集中在一个地方
- **多环境支持**：开发、测试、生产环境配置分离
- **类型安全**：用 TypeScript 或 Joi 校验配置
- **安全**：敏感信息不提交到 Git

### 第三步：核心代码解读

#### 1. 环境配置文件（`.env.development`）

```bash
# 服务器配置
PORT=3000
NODE_ENV=development

# 数据库配置（示例用内存存储，后续可换成 MongoDB）
# MONGODB_URI=mongodb://localhost:27017/todoapp

# JWT 配置
JWT_SECRET=dev_secret_key_12345
JWT_EXPIRES_IN=7d

# 日志配置
LOG_LEVEL=debug

# CORS 配置
CORS_ORIGIN=http://localhost:3000
```

**.env.example**（提交到 Git，作为模板）：

```bash
# 服务器配置
PORT=3000
NODE_ENV=development

# 数据库配置
# MONGODB_URI=your_mongodb_uri_here

# JWT 配置
JWT_SECRET=your_jwt_secret_here
JWT_EXPIRES_IN=7d

# 日志配置
LOG_LEVEL=info

# CORS 配置
CORS_ORIGIN=http://your-frontend-domain.com
```

**关键点**：
- `.env.development`、`.env.test`、`.env.production` **不提交 Git**
- `.env.example` **提交到 Git**，作为配置模板

---

#### 2. 配置校验（`config/validation.js`）

```javascript
const Joi = require('joi');

const configSchema = Joi.object({
  PORT: Joi.number().default(3000),
  NODE_ENV: Joi.string().valid('development', 'test', 'production').default('development'),
  
  // 数据库配置（可选，原型阶段用内存存储）
  MONGODB_URI: Joi.string().uri().optional(),
  
  // JWT 配置（必填）
  JWT_SECRET: Joi.string().min(10).required(),
  JWT_EXPIRES_IN: Joi.string().default('7d'),
  
  // 日志配置
  LOG_LEVEL: Joi.string().valid('error', 'warn', 'info', 'debug').default('info'),
  
  // CORS 配置
  CORS_ORIGIN: Joi.string().default('*')
}).unknown(true);  // 允许其他环境变量

const validateConfig = (env) => {
  const { error, value } = configSchema.validate(env);
  if (error) {
    throw new Error(`配置校验失败: ${error.message}`);
  }
  return value;
};

module.exports = validateConfig;
```

**好处**：
- 启动时校验配置，缺少必填项立即报错
- 类型转换（如 `PORT` 从字符串转数字）

---

#### 3. 配置入口（`config/index.js`）

```javascript
require('dotenv').config({ path: `.env.${process.env.NODE_ENV || 'development'}` });
const validateConfig = require('./validation');

// 校验配置
const env = validateConfig(process.env);

// 统一导出配置
const config = {
  server: {
    port: env.PORT,
    nodeEnv: env.NODE_ENV
  },
  database: {
    mongodbUri: env.MONGODB_URI
  },
  jwt: {
    secret: env.JWT_SECRET,
    expiresIn: env.JWT_EXPIRES_IN
  },
  log: {
    level: env.LOG_LEVEL
  },
  cors: {
    origin: env.CORS_ORIGIN
  }
};

module.exports = config;
```

**使用方式**（在 `server.js` 中）：

```javascript
const config = require('./config');
const app = express();

// 使用配置
app.listen(config.server.port, () => {
  console.log(`🚀 服务器运行在 http://localhost:${config.server.port}`);
  console.log(`📝 当前环境: ${config.server.nodeEnv}`);
});
```

## 核心技巧

### 1. 让 Claude Code 生成"完整的配置管理方案"

❌ **不好**：只生成 `.env` 文件，不包含校验和集中管理
✅ **好**：明确说出你要的完整方案

```
请帮我生成配置管理方案，包含：
1. 多环境 .env 文件（development / test / production）
2. 配置校验（用 Joi）
3. 统一配置入口（config/index.js）
4. .gitignore 配置（防止敏感信息提交）
```

---

### 2. 敏感信息永远不提交 Git

**原则**：
- `.env.development`、`.env.production` → 加入 `.gitignore`
- `.env.example` → 提交到 Git，作为模板（不包含真实密钥）

**让 Claude Code 帮你更新 `.gitignore`**：

```
请帮我更新 .gitignore，确保：
1. 所有 .env 文件都被忽略
2. 但保留 .env.example
```

---

### 3. 用 Joi 校验配置，别手动检查

❌ **不好**：

```javascript
if (!process.env.JWT_SECRET) {
  throw new Error('JWT_SECRET 未配置');
}
```

✅ **好**：用 Joi 声明式校验

```javascript
const schema = Joi.object({
  JWT_SECRET: Joi.string().min(10).required()
});
```

**好处**：
- 校验规则集中管理
- 支持类型转换、默认值

---

### 4. 配置分层，别散落各处

❌ **不好**：在代码里直接用 `process.env`

```javascript
const port = process.env.PORT || 3000;
const secret = process.env.JWT_SECRET;
```

✅ **好**：通过 `config/index.js` 统一访问

```javascript
const config = require('./config');
const port = config.server.port;
const secret = config.jwt.secret;
```

**好处**：
- 配置集中管理，方便查找
- 支持默认值、类型转换

## 常见问题

### Q1：如何在部署时动态设置环境变量？

**方案 1**：在服务器上创建 `.env.production` 文件

```bash
# 服务器上
cd /path/to/your/app
echo "JWT_SECRET=production_secret_123" > .env.production
echo "MONGODB_URI=mongodb://prod-db:27017/todoapp" >> .env.production
```

**方案 2**：用云服务的环境变量功能（如 Heroku、Vercel）

```
# Heroku 示例
heroku config:set JWT_SECRET=production_secret_123
heroku config:set MONGODB_URI=mongodb://prod-db:27017/todoapp
```
