# 2.7 GraphQL API 开发

## 场景描述

REST API 写多了，你有没有遇到过这些烦恼？

- 前端要的数据和后端返回的不一样，多拿了浪费
- 改一个字段，整个端点都要版本升级
- 手机端和 Web 端需要不同的数据格式，却只有一套 API

GraphQL 就是来解决这些问题的——前端自己定义需要什么数据，后端一次性返回。

**Claude Code 可以帮你从零搭建一个生产级的 GraphQL API。**

---

## 案例：博客系统 GraphQL API

延续 2.2 节的博客系统，这次用 GraphQL 实现：
- 类型安全的 Schema 定义
- 按需获取字段，不多不少
- 实时订阅（新评论通知）
- 分页与过滤
- 认证与权限

---

## 第一步：初始化项目

**提示词：**

```
在当前目录的 ./blog-graphql/ 文件夹，创建博客系统的 GraphQL API：

技术栈：
- Node.js + Apollo Server 4
- TypeScript
- Prisma ORM + SQLite
- GraphQL Subscriptions（实时功能）
- JWT 认证

功能：
- 用户认证（注册、登录、刷新 Token）
- 文章 CRUD（支持分页、搜索、分类筛选）
- 评论功能（支持嵌套回复）
- 分类管理
- 实时订阅（新评论、新文章）

Schema 要求：
- 用 SDL 风格定义类型
- 支持 Relay 风格分页（Connection/Edge）
- 输入类型（Input Types）用于复杂参数
- 支持字段级别的权限控制
- 包含 deprecation 标记（旧字段迁移用）

生成完整的 package.json、tsconfig.json、schema、resolvers、middleware、prisma schema。
```

## 第二步：核心代码解析

### Schema 定义（src/schema/typeDefs.ts）

```typescript
export const typeDefs = `#graphql
  # ---------- 标量类型 ----------
  scalar DateTime

  # ---------- 枚举 ----------
  enum Role {
    ADMIN
    EDITOR
    USER
  }

  enum PostStatus {
    DRAFT
    PUBLISHED
    ARCHIVED
  }

  # ---------- 输入类型 ----------
  input CreateUserInput {
    username: String!
    email: String!
    password: String!
  }

  input LoginInput {
    email: String!
    password: String!
  }

  input CreatePostInput {
    title: String!
    content: String!
    categoryId: ID
    status: PostStatus = DRAFT
  }

  input UpdatePostInput {
    title: String
    content: String
    categoryId: ID
    status: PostStatus
  }

  input PostWhereInput {
    categoryId: ID
    status: PostStatus
    search: String
    authorId: ID
    createdAfter: DateTime
    createdBefore: DateTime
  }

  input CreateCommentInput {
    postId: ID!
    parentId: ID
    content: String!
  }

  input PaginationInput {
    first: Int
    after: String
    last: Int
    before: String
  }

  # ---------- 接口 ----------
  interface Node {
    id: ID!
  }

  type User implements Node {
    id: ID!
    username: String!
    email: String!
    role: Role!
    avatar: String
    posts: [Post!]!
    createdAt: DateTime!
  }

  type Post implements Node {
    id: ID!
    title: String!
    slug: String! @deprecated(reason: "Use 'id' instead for URL construction")
    content: String!
    excerpt: String
    status: PostStatus!
    author: User!
    category: Category
    tags: [String!]!
    comments: [Comment!]!
    commentCount: Int!
    viewCount: Int!
    publishedAt: DateTime
    createdAt: DateTime!
    updatedAt: DateTime!
  }

  type Comment implements Node {
    id: ID!
    content: String!
    author: User!
    post: Post!
    parent: Comment
    replies: [Comment!]!
    depth: Int!
    createdAt: DateTime!
  }

  type Category implements Node {
    id: ID!
    name: String!
    slug: String!
    description: String
    postCount: Int!
    posts: PostConnection!
  }

  # ---------- Relay 分页 ----------
  type PostEdge {
    node: Post!
    cursor: String!
  }

  type PostConnection {
    edges: [PostEdge!]!
    pageInfo: PageInfo!
    totalCount: Int!
  }

  type PageInfo {
    hasNextPage: Boolean!
    hasPreviousPage: Boolean!
    startCursor: String
    endCursor: String
  }

  # ---------- 认证相关 ----------
  type AuthPayload {
    token: String!
    refreshToken: String!
    user: User!
  }

  type RefreshPayload {
    token: String!
    user: User!
  }

  # ---------- 订阅 ----------
  type Subscription {
    commentAdded(postId: ID!): Comment!
    postPublished: Post!
  }

  # ---------- 查询根类型 ----------
  type Query {
    # 节点查询（Relay 规范）
    node(id: ID!): Node

    # 用户
    me: User
    user(id: ID!): User
    users: [User!]!

    # 文章
    post(id: ID!): Post
    posts(
      where: PostWhereInput
      pagination: PaginationInput
      orderBy: String = "createdAt"
      orderDirection: String = "DESC"
    ): PostConnection!
    postsByCategory(categorySlug: String!, pagination: PaginationInput): PostConnection!
    featuredPosts: [Post!]!

    # 分类
    categories: [Category!]!
    category(id: ID!): Category

    # 工具
    _service: _Service!
  }

  # ---------- 变更根类型 ----------
  type Mutation {
    # 认证
    register(input: CreateUserInput!): AuthPayload!
    login(input: LoginInput!): AuthPayload!
    refreshToken(token: String!): RefreshPayload!

    # 文章
    createPost(input: CreatePostInput!): Post!
    updatePost(id: ID!, input: UpdatePostInput!): Post!
    deletePost(id: ID!): Boolean!
    publishPost(id: ID!): Post!

    # 评论
    createComment(input: CreateCommentInput!): Comment!
    deleteComment(id: ID!): Boolean!

    # 分类（仅管理员）
    createCategory(name: String!, description: String): Category! @requiresRole(role: ADMIN)
    updateCategory(id: ID!, name: String, description: String): Category! @requiresRole(role: ADMIN)
    deleteCategory(id: ID!): Boolean! @requiresRole(role: ADMIN)
  }
`;
